# Percentage, Discount & Tip Calculator — Gamility Tools

An all-in-one financial and mathematical percentage computing utility. Features real-time reactive calculations for general percentages, percentage increases/decreases, retail store discounts with sales tax, business profit margins & markups, and restaurant tip/bill splitting.

---

## 🌟 Features & Highlights

- **⚡ 5 Dedicated Calculation Modes:**
  1. **Direct Percentage:** "What is X% of Y?" and "X is what percent of Y?"
  2. **Percentage Change:** Calculate percentage increase or decrease between two values with absolute difference and visual trend badges.
  3. **Retail Discount & Sales Tax:** Original price minus discount percentage with optional sales tax and savings calculation.
  4. **Profit Margin & Markup:** Calculate selling prices, gross profit dollars, markup percentage, and profit margin.
  5. **Tip & Bill Splitter:** Restaurant tipping with standard presets (10%, 15%, 18%, 20%, 25%) and bill division per person.
- **🔢 Step-by-Step Formula Breakdown:** Every calculation includes an intuitive mathematical explanation showing the exact formula used.
- **🌐 Currency Localization:** Switch effortlessly between `$`, `€`, `£`, `₹`, and `¥`.
- **📋 1-Click Clipboard Copies:** Copy calculated results, savings breakdowns, or formulas with a single tap.
- **🔒 100% Client-Side Privacy:** Zero network transmissions. All calculations execute strictly in your local browser memory.

## 🚀 Quick Start

### Local Preview
Open `index.html` directly in any modern browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or serve via any static HTTP server:
```bash
npx serve .
```
